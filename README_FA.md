# دفتر وکالت – نسخه آغازین

این پروژه یک اپلیکیشن بومی اندروید است و اطلاعات را در پایگاه داده SQLite داخل گوشی ذخیره می‌کند. برای کارکرد روزمره به اینترنت یا حساب کاربری نیاز ندارد.

## امکانات نسخه ۱
- ثبت پرونده‌ها، موکلان، جلسات و یادداشت‌ها
- نمایش و جست‌وجوی اطلاعات
- حذف مورد با لمس طولانی
- تهیه نسخه پشتیبان JSON در محلی که کاربر انتخاب می‌کند
- رابط راست‌چین فارسی

## ساخت APK
1. Android Studio را نصب و اجرا کنید.
2. از مسیر **Open** پوشه `DaftarVekalat` را انتخاب کنید.
3. اجازه دهید Gradle Sync و دانلود ابزارهای لازم انجام شود.
4. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** فایل APK را بسازید.
5. فایل خروجی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

حداقل نسخه اندروید: Android 6.0 (API 23).

## نکات
- نسخه فعلی، نسخه اولیه است؛ هنوز قفل برنامه، ویرایش رکوردها، بازیابی نسخه پشتیبان، تقویم شمسی خودکار و اعلان زمان‌دار اضافه نشده‌اند.
- تا زمان افزودن رمزگذاری پایگاه داده، اطلاعات حساس موکلان را فقط روی گوشی امن و قفل‌شده نگه دارید.
- برای جلوگیری از از دست رفتن داده‌ها، مرتباً نسخه پشتیبان تهیه کنید.
